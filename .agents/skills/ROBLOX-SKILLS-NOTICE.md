# Third-party skills: roblox-skills

The `roblox-*` skill folders in this directory (23 skills) were copied from
[EL4CTEO/roblox-skills](https://github.com/EL4CTEO/roblox-skills) at commit
`f94b0e499c124c11b30cd2cc0a57267090943049` (2026-11-03), unchanged.
The `roblox` skill (no suffix) is this project's own and is not part of that set.

`.claude/skills` is a symlink to this folder so Claude Code sees the same skills
as Codex, Cursor and other agents that read `.agents/skills`.

To update: clone the upstream repo and copy its `skills/` folder over these
`roblox-*` folders, then bump the commit above.
